# Lambda Functions and Functional Programming Assignment

## About

This repository contains my Python assignment on lambda functions and functional programming concepts.

In this assignment, I practiced using:

- Lambda functions
- map()
- filter()
- sorted()

## Topics Covered

### Lambda Functions

I created lambda functions to:

- Double a number
- Find the remainder of two numbers
- Check whether a number is divisible by 5
- Find the smaller of two numbers
- Convert Celsius into Fahrenheit

### map()

I used map() with lambda to:

- Add 5 to every number in a list
- Convert names into uppercase

### filter()

I used filter() with lambda to:

- Find ages that are 18 or above
- Find names having more than 4 characters

### sorted()

I used sorted() with lambda to arrange students according to their marks from highest to lowest.
